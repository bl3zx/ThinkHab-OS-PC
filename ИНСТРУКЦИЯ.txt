ThinkHab для Windows — КАК ПОЛУЧИТЬ .EXE
========================================

СПОСОБ А (рекомендуется, ничего не нужно устанавливать): сборка на GitHub
-------------------------------------------------------------------------
1. Зайдите на github.com и войдите в свой аккаунт.
2. Вверху справа "+" -> New repository. Название: thinkhab-pc. Public. Create repository.
3. Нажмите ссылку "uploading an existing file".
4. Откройте распакованную папку ThinkHabPC, выделите ВСЁ внутри (Ctrl+A) и перетащите в окно браузера.
   Должны появиться: папки app и build, файлы main.js, preload.js, package.json.
   Нажмите Commit changes.
5. Скрытая папка .github могла НЕ загрузиться. Проверьте: на главной странице репозитория должна быть
   папка .github. Если её нет:
   Add file -> Create new file -> в поле имени впишите  .github/workflows/build-exe.yml
   и вставьте текст из файла build-exe.yml (лежит в этой папке: .github\workflows\build-exe.yml,
   откройте его Блокнотом). Нажмите Commit changes.
6. Вкладка Actions. Подождите 4-8 минут, пока появится зелёная галочка.
7. Нажмите на запись с галочкой -> внизу раздел Artifacts -> скачайте ThinkHab-exe.
8. Распакуйте архив. Внутри ThinkHab-1.2.8.exe — это и есть программа. Запускайте двойным щелчком.
   Windows может показать синее окно "Windows защитил ваш компьютер":
   нажмите "Подробнее" -> "Выполнить в любом случае" (программа не подписана платным сертификатом).

СПОСОБ Б: сборка на своём компьютере
------------------------------------
1. Установите Node.js (версия LTS) с сайта nodejs.org (кнопка LTS, всё по умолчанию).
2. Откройте папку ThinkHabPC, в адресной строке проводника впишите cmd и нажмите Enter.
3. Команды по очереди:
      npm install
      npm start            (запуск для проверки, без сборки)
      npm run dist         (сборка; готовый файл появится в папке dist)

КАК ПОЛЬЗОВАТЬСЯ STEAM
----------------------
1. Установите Steam и войдите в свой аккаунт (хотя бы один раз).
2. В ThinkHab: Игры -> кнопка "Привязать библиотеку Steam"
   (или Настройки -> Библиотека -> Привязать библиотеку Steam).
3. Выберите свой аккаунт из списка (лаунчер находит аккаунты, входившие в Steam на этом ПК)
   или вставьте SteamID64 / ссылку на профиль. Нажмите "Привязать".
4. Чтобы появились ВСЕ игры аккаунта, в Steam должна быть открыта информация об играх:
   Steam -> профиль -> Редактировать профиль -> Настройки приватности -> "Информация об играх" = Открытая.
   Или вставьте Web API ключ (необязательное поле; ключ создаётся на steamcommunity.com/dev/apikey).
   Если профиль закрыт и ключа нет, всё равно будут видны игры, установленные на этом ПК.
5. Нажатие на игру: если она установлена (проверяется по файлам Steam на этом ПК) — запускается через Steam.
   Если нет — лаунчер напишет, что игра не установлена на этом ПК, и предложит установить её в Steam.

УПРАВЛЕНИЕ
----------
Мышь (листание — зажать и тянуть), стрелки + Enter/Esc, геймпад. F11 — выйти из полного экрана и вернуться.
"Выключение" -> "Выключить консоль" закрывает программу.

КАК ОБНОВИТЬ ЛАУНЧЕР В БУДУЩЕМ
------------------------------
Интерфейс лежит в файле app\index.html. Замените его новой версией, загрузите изменение на GitHub
(Add file -> Upload files) — сборка запустится сама, новый .exe появится во вкладке Actions.

ЕСЛИ СБОРКА КРАСНАЯ
-------------------
Откройте запись во вкладке Actions, нажмите на красный шаг "build", скопируйте текст ошибки
и отправьте его нейросети вместе с этим архивом.
